**Authenticity / worthiness** — people at the profile stage only (validate / clean up / worthy, or a scored people list). Treat as must-have fails when not worthy. Snapshot stage leaves these unknown unless the snapshot shows them. ICP and the user's rubric stay their own criteria. One soft signal alone is not enough; two or more of these gates failing, or a clearly fake or placeholder profile, fails the row.

| key | Pass | Fail |
| --- | --- | --- |
| `enoughConnections` | 100–500 okay; 500+ good | under 100 (under 10 = useless, 10–100 = very poor); unknown or missing count |
| `hasActivityOrSubstance` | recent experience, about text, or other signs of a real working profile | dormant shell / no activity |
| `profileFilled` | photo, experience detail, enough about/headline | thin unfilled / placeholder |

When building a fitment column, use those keys with `mustHave: true` and descriptions that match the Pass / Fail columns.
