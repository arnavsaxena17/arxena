Small companies (under ~200 people) rarely carry a titled VP or director: the holder is a head, a CTO or a founder. When most companies on the list are small, say so and read the role one rung wider before the pilot; a zero-found pilot on titled VPs at seed-stage companies is expected, not a finding about the market.

Expand in the user's words. Never drop a role they named; never add a lower-level one they did not ask for.
