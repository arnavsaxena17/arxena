**Later checks** are facts a profile or company page cannot show. List them in the brief; tell the user in one line; never score or filter on them. An unknown must-have fails a row at the profile stage, so putting these in the rubric would fail every row.

- **Recruiting:** pay, notice period, age, willingness to move or switch, proof of numbers, family or lifestyle limits. Checked in conversation or on the CV, not in sourcing.
- **Sales:** budget, timing, current vendor, intent.
- **Unverifiable claims** (exact territory revenue, a company's internal numbers): say so plainly, move them here, never estimate them and never build a column for them.
- **Age.** Ignore unless the user states a hard cap more than once. Then use it only where a source has a native filter (Naukri). Never filter LinkedIn on age: first-job or education years drop people who leave those dates out. Never guess age from a photo. Say in the assumptions line that age was ignored.
