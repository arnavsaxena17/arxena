Evidence comes in levels, cheapest first: **snapshot** (what a search previews), **full profile** (`fetch_profiles`), **CV** (only for rows that came from a CV or a Naukri upload). A row climbs one level at a time. Stop climbing when it fails a must-have or when the next level cannot answer what is still unknown. Rows from a Naukri or CV upload enter at the profile level and are scored with `stage: "profile"`. Never re-fetch a row that already has a profile.
