The Posts API gives each workspace a programmatic way to search LinkedIn posts with a workspace-scoped Bearer token.

For full endpoint docs and an interactive playground, use the **API Reference**:

## Data source aliases

| Alias | Typical use |
|------|-------------|
| `auto` | Unipile Sales Navigator, then Recruiter/classic, then Harvest |
| `harvest` | Harvest LinkedIn post search ([post search](https://docs.harvestapi.io/linkedin-api-reference/post/search)) |
| `unipile` | LinkedIn classic post search via Unipile |
| `pool` | Shared Unipile Sales Navigator pool |
| `recruiter` | Recruiter-connected Unipile account |

If Unipile is not available, `auto` uses Harvest.

## OpenAPI

curl https://app.arxena.com/posts-api/openapi.json
