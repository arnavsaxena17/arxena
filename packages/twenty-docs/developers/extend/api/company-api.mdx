The Company API gives each workspace a programmatic way to search companies with a workspace-scoped Bearer token.

For full endpoint docs and an interactive playground, use the **API Reference**:

  </Card>
  <Card title="Authentication" icon="lock" href="/api-reference/authentication">

  </Card>
</CardGroup>

## Data source aliases

| Alias | Typical use |
|------|-------------|
| `auto` | Unipile Sales Navigator, then Recruiter/classic, Harvest, then index |
| `index` | Arxena companies Elasticsearch index |
| `unipile` | LinkedIn via an explicit Unipile `accountId` |
| `pool` | Shared Unipile Sales Navigator pool |
| `recruiter` | Recruiter-connected Unipile account |
| `harvest` | Harvest LinkedIn company search ([company search](https://docs.harvestapi.io/linkedin-api-reference/company/search)) |

## OpenAPI

```bash
curl https://app.arxena.com/company-api/openapi.json
```
