The Jobs API gives each workspace a programmatic way to search jobs with a workspace-scoped Bearer token.

For full endpoint docs and an interactive playground, use the **API Reference**:

  <Card title="Authentication" icon="lock" href="/api-reference/authentication">

  </Card>
</CardGroup>

## Data source aliases

| Alias | Typical use |
|------|-------------|
| `auto` | Unipile Sales Navigator, then Recruiter/classic, then Harvest |
| `unipile` | LinkedIn classic job search via Unipile |
| `pool` | Shared Unipile Sales Navigator pool |
| `recruiter` | Recruiter-connected Unipile account |
| `harvest` | Harvest LinkedIn job search ([job search](https://docs.harvestapi.io/linkedin-api-reference/job/search)) |

curl https://app.arxena.com/jobs-api/openapi.json
