## Getting started

1. [Create an API key](/api-reference/authentication) in **Settings → APIs & Webhooks**
2. Open any endpoint in this API Reference
3. Paste your Bearer token in the playground Authorization field
4. Click **Send** to call the live API

## Base URL

| Environment | Base URL |
|-------------|----------|
| Production | `https://app.arxena.com` |
| Local development | `http://localhost:3000` |

Use the server dropdown in the interactive playground to switch between production and local. Cloud examples in this reference use `https://app.arxena.com`.

## What is covered here

| Surface | In this API Reference | Notes |
|---------|------------------------|-------|
| People API | Yes — interactive playground | Fixed REST surface under `/people-api` |
| Company API | Yes | Fixed REST surface under `/company-api` |
| Jobs API | Yes | Fixed REST surface under `/jobs-api` |
| Posts API | Yes | Fixed REST surface under `/posts-api` |
| Workspace credits | Yes — `GET /people-api/credits` | Org chart, reveal, and API balances |
| Core / Metadata CRM APIs | No | Schema is workspace-specific; use the in-app explorer under **Settings → APIs & Webhooks** for custom objects |
