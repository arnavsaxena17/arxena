---
title: 'List taxonomy tree'
description: Public nested function-root → function labels and grade dropdown values.
openapi: 'openapi/people-api.json GET /people-api/taxonomy/tree'
---

Ungated **nested nouns**: each function root lists child function labels (`id` / `label` only). `gradeLevels` is the dropdown for optional `stdGrade` (`entry` | `mid` | `leadership`). No Boolean operators. Use with [Search people by taxonomy](/api-reference/people/search-people-by-taxonomy).
