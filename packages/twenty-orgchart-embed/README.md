# twenty-orgchart-embed

Inline org chart embed SDK for third-party websites.

Build:

```bash
yarn nx build twenty-orgchart-embed
```

Output: `dist/arxena-orgchart.inline.js` — copy to `packages/twenty-website/public/embed/` for hosting.

See [docs/org-chart-embed.md](../../docs/org-chart-embed.md).
